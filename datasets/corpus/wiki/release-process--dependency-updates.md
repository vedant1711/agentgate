# Release Process: Dependency Updates

## Summary
This page describes how Northwind Robotics handles dependency updates within release process.

## Key facts
- The turnaround time for dependency updates is 4 business days.
- The on-call sre owns this process.
- Requests are processed within 3 business days.

## Escalation
Contact the Reliability team if the process stalls for more than 6 business days.
